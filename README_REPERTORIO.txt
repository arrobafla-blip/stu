# REPERTÓRIO. — Documento Mestre Definitivo

Este pacote contém a especificação principal para construir o site pessoal de estudos REPERTÓRIO.

## Arquivo incluído
- `REPERTORIO_Documento_Mestre_Definitivo.docx` — documento editável com visão do produto, identidade visual, arquitetura, currículo, modelo editorial, conteúdo inicial, funcionalidades, requisitos técnicos, bibliografia, plano de implementação e critérios de aceitação.

## Importante
Este ZIP contém a **especificação**, não os arquivos executáveis do site. Para publicar um site no GitHub Pages, será necessário implementar os arquivos HTML, CSS, JavaScript e os dados descritos no documento.

## Publicação
O documento pode ser guardado no repositório GitHub como referência do projeto. O GitHub Pages publica arquivos estáticos como HTML/CSS/JS; um DOCX isolado não se transforma em site.
